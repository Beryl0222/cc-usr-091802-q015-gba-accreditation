# 湾区参赛资格通行

用于协同粤港澳赛事名单、证件核验、例外复核和离线场馆通行。

`fixtures/sample.json` 保存可公开的领域样例,只用于说明数据边界,不包含真实个人资料或业务凭据。

执行 `python3 service.py --check` 可检查项目身份,运行 `python3 -m unittest discover -s tests -v` 可核对基础契约与领域行为。服务启动后,`/health` 返回项目标识。

## 领域核心(accreditation 包)

| 模块 | 职责 |
| --- | --- |
| `rules` | 赛区发布带生效期的材料规则;按身份与职责推导适用规则,同材料取最新版本 |
| `cases` | 名单版本化提交与换人,自动生成待核项目;规则更新后重算在册人员项目 |
| `decisions` | 审核、续证、资格申诉、临时医疗豁免,全部形成带依据的新决定 |
| `clearance` | 汇聚名单、决定与冲突状态得出通行结论;两地冲突只暂停个人并派单复核 |
| `offline` | 断网闸机的短期签名凭证(HMAC,默认 30 分钟)与恢复后的幂等回执入库 |
| `board` | 赛前看板:缺件与到期项按紧迫程度排列 |
| `audit` | 赛后从一条入场记录查回名单版本、核验机构、例外决定与设备回执 |
| `views` | 按角色裁剪的读取:原件仅授权审核岗可见,场馆与接驳只见通行结论 |

## 关键约束

- 证件、保险、反兴奋剂声明、未成年监护同意分别由规则指定的不同机构查验。
- 换人、续证、资格申诉、临时医疗豁免与冲突复核都必须附带依据,否则拒绝记录。
- 已发生的入场记录保存当时的结论与规则快照,不随后来规则或名单改变。
- 两地结论冲突时只暂停相关个人并交赛事指定复核人员,不扩大到全队。
- 断网闸机只认短期签名凭证;恢复联网后重复上传同一回执仍只算一次通行。
- 材料原件仅向授权审核岗开放;其他角色只能拿到足以判断通行的结论。
